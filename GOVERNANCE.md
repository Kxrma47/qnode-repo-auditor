# Project governance

QNode is currently maintained by [Mahidul Haque (`Kxrma47`)](https://github.com/Kxrma47).
There is no steering committee or second maintainer at present. Contributors may propose
changes through [issues](https://github.com/Kxrma47/qnode-repo-auditor/issues),
[discussions](https://github.com/Kxrma47/qnode-repo-auditor/discussions), and pull requests.

## Roles and decisions

- **Maintainer:** Mahidul Haque sets project scope, reviews changes, manages GitHub App
  permissions and hosting, handles private security reports, and approves releases.
- **Contributor:** Anyone may report a problem, suggest a feature, review a pull request,
  improve documentation, or submit code under [CONTRIBUTING.md](CONTRIBUTING.md).

The maintainer makes final decisions after considering technical evidence and community
feedback. A proposal is not accepted merely because it has a pull request or a passing CI
check. Changes to permissions, data handling, or public security claims require an explicit
maintainer review. The maintainer may defer a proposal with a written reason in the issue
or pull request. Contributors can ask for reconsideration there and provide new evidence.

This document describes the current, single-maintainer model; it does **not** claim that a
backup maintainer or emergency release arrangement exists. Changes to roles or decision
making will be documented here before those roles are used as badge evidence.
