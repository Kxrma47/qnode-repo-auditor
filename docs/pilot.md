# Maintainer pilot

QNode is looking for a small number of maintainers willing to test one public pull request.
No installation is required for the first scan.

## What the pilot includes

1. A path-only QNode report for one public pull request.
2. A short review of false positives, missed signals, and confusing wording.
3. Optional help defining one `.qnode.json` change contract for a real cross-file rule.
4. Optional installation of the local QNode Action after the maintainer reviews its behavior.

## What feedback helps

- Which signal changed what you reviewed?
- Which signal was wrong or too noisy?
- Which missing signal would save time on another pull request?
- Would you use the Action again?

Please use [discussion #6](https://github.com/Kxrma47/qnode-repo-auditor/discussions/6)
or open a signal request. Never include private repository paths, credentials, or source code.
